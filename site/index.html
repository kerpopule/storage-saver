This is an early public beta, not a promise of one-click cleanup. Start with a small folder and review the results before granting broader access. From version 0.3.1, use Storage Saver → Check for Updates to install signed updates in the app. Daily checks can be turned off in the same menu. Older versions need one final manual replacement.

Get Storage Saver ↗
  1. Unzip the download and drag Storage Saver.app into Applications.
  2. Open the app. Your inventory is built locally. Large disks can take time and need room for the catalog and its replacement during refresh.
  3. For broader coverage, grant Storage Saver Full Disk Access in System Settings → Privacy & Security. Root permission alone is not Full Disk Access.
  4. Use Invite an agent to copy local instructions. Grant only the folders and permissions you actually intend.
Beta limitations & safety

Apple Silicon build qualified on macOS 27. Intel, older macOS releases and Windows are not qualified. macOS permission dialogs still require your consent. The index can be large, roughly a kilobyte per entry, and refresh needs space for both catalogs. Same-size duplicate leads are not verified duplicates. Physical selection measurements are not guaranteed deletion savings. No permanent-delete operation is exposed. Native elevation helpers pass synthetic tests; the interactive authorization flow is not yet fully qualified. Always preserve a backup of important work.

LOCAL. PRIVATE. YOURS.

Your filenames are
none of our business.

The desktop app works locally without an account, cloud storage, telemetry or an AI API key. It indexes file metadata. Optional native grants can permit file-content access to the agent you authorize. If you use a third-party AI service, that service’s privacy terms apply to what you share with it.

The website serves the app download through Cloudflare. The desktop updater contacts storagesaver.app for signed release information and downloads; system profiling is disabled, and automatic checks can be turned off. Normal hosting requests are processed by Cloudflare; neither the update feed nor the site accesses your local disk or inventory.
