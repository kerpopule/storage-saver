own licenses. SQLite is bundled by libsqlite3-sys; SQLite itself is public domain.
SPDX metadata below comes from the locked Cargo package manifests. Review original
licenses before redistributing binary bundles. No proprietary assets or fonts are used.

## Native updater

Sparkle 2.10.0 is bundled for macOS updates. Upstream: https://github.com/sparkle-project/Sparkle . Its BSD-style license and bundled component notices are preserved in `licenses/Sparkle-LICENSE.txt` and the app's Resources. The release dependency is pinned by SHA-256; update archives and feeds are separately Ed25519 signed. No Sparkle signing private key is distributed.

## Optional browser tests

Playwright 1.62.1 and playwright-core: Apache-2.0. Browser binaries are not bundled.
The application runs without Node, Playwright or a browser automation dependency.
